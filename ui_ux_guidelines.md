# UI/UX Guidelines (MVP)

## 1. The "Simple" Interface
The MVP will solely focus on the "Simple" interface, designed to reduce cognitive load.
* **Minimalist Design:** Eliminate complex dashboards, data visualizations, and heavy metrics.
* **Core Interaction:** The primary focus is the Voice Recording button for "brain dumps".
* **Vision Interface:** A clean, expandable text area for writing the Vision. Below this, standard Socratic questions will appear to prompt the user, without cluttering the main writing space.

## 2. Aesthetics
* **Theme:** As per guidelines, prioritize Rich Aesthetics (vibrant but curated color palettes, dark modes, subtle glassmorphism). 
* **Typography:** Clean, modern, sans-serif (e.g., Inter or Roboto).
* **Feedback:** Micro-animations for buttons (especially the voice recording toggle) to make the interface feel alive and responsive.
