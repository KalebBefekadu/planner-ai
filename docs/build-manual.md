# Personal MVP Build Manual

[GitHub delivery manual and live checklist](https://github.com/KalebBefekadu/planner-ai/issues/114)

## Goal

Replace the owner's actual everyday Notion workflows and make personal planning useful in one real authenticated app. Establish the must-have workflow inventory before claiming that Markdown imports replace native databases, relations, formulas, attachments, or sharing.

## Authority and baseline

The roadmap owns stage order; GitHub issues own ticket scope, dependencies and closure evidence. This file is a navigation index with short descriptions, not a second status board. Planning baseline: integration commit `8e6e75c` on 2026-09-08; verify current code before implementation. The old prototype issues #1-99 remain historical.

## How to execute

1. Begin the owner workflow inventory (MVP-01) and Preview pattern inventory (UI-01); implement PL-05 as the first code ticket.
2. Claim one issue with an isolated worktree and exact writable paths in the active task contract. Keep Codex and Claude work non-overlapping.
3. Reuse existing tested behavior. A verification ticket may close with evidence and zero code changes; a code ticket requires passing acceptance cases.
4. Link PR, commit, checks, limitations and user-visible change description to the issue. Attach only sanitized evidence.
5. Treat dependency completion as an exit gate, not a ban on independent preparation. Never infer owner approval from silence.
6. Reconcile the umbrella checklist after integration. Add discovered blockers as linked tickets before closing their parent.

The real app gets every accepted Preview pattern. Extract shared components, compare desktop/mobile behavior, preserve future concepts in their tickets, and delete the duplicate route only after the mapping is complete.

## Release evidence

Report gates as implemented, locally verified, deployed verified and owner accepted. Do not calculate completion from lines of code or closed legacy issues. A representative import, usable Notes and Planner, core AI/MCP, real recovery, Preview retirement and seven days of owner use must each have evidence. Keep originals until the owner approves the switch.
